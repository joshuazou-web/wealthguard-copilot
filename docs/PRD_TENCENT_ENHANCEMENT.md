# PRD：WealthGuard × 腾讯自选股证据与质量增强层

## 目标用户与问题

- **证券研究用户**：在自选股/资讯/AI 回答中看到结论，但难以快速判断它来自哪份、哪一版、哪一页材料。
- **产品经理与算法/评测人员**：知道模型会错，但缺少统一错误分类、责任模块、修复状态和回归证据。
- **合规与运营复核人员**：需要确认系统在资料过期、证据冲突、个性化建议和交易执行边界前正确停止。

## 产品目标

在不替代腾讯自选股行情、资讯、社区、提醒、账户和券商交易的前提下，让关键证券结论“可核验、可停止、可复盘、可迭代”。原型验收目标是证明产品闭环，不声称完成生产集成。

## 非目标

- 不建设实时行情、内容推荐、社区、选股榜或交易；
- 不输出唯一最佳产品、收益预测或个性化投资建议；
- 不连接腾讯、微信或券商账户；
- 不把固定种子合成评测写成真实用户准确率。

## 核心流程

1. 宿主产品提交证券、文件版本、问题与候选结论；
2. WealthGuard 识别财报 / 公告 / 比较场景；
3. 核验代码、日期、版本、证据位置与计算参数；
4. 策略层输出 pass / caution / abstain / refuse；
5. 用户可打开原文与计算轨迹；
6. 失败进入质量运营台，关联责任模块、修复状态和回归编号；
7. 匿名评测结果可导出，真实交易继续由合作券商承接。

## 优先级与验收

| 优先级 | 能力 | 原型验收标准 |
| --- | --- | --- |
| P0 | 三场景证据核验 | 官方资料带日期、版本与页码/段落；缺证据时弃权 |
| P0 | 坏案例分类与后台 | 16 类错误进入代码；支持场景、类型、严重度、模型和资料版本筛选 |
| P0 | 安全边界 | 个性化建议和交易请求由确定性策略拒绝 |
| P0 | 可复现评测 | 命令生成指标与失败样本；明确合成分母 |
| P1 | 宿主上下文契约 | 展示输入/输出 schema；敏感账户字段不进入系统 |
| P1 | 匿名导出 | 当前筛选结果导出 JSON，无密钥与个人金融信息 |
| P2 | 腾讯内部真实集成 | 仅在接口、授权、合规和延迟要求确认后实施 |

## 指标树

- **可信完成率** = 正确回答 + 正确 caution/abstain/refuse / 全部有效任务；
  - 事实正确率、关键结论引用覆盖率、引用支持率、位置可解析率；
  - 时效检查、计算一致、工具选择与参数正确率；
  - 建议/执行拒绝准确率、安全降级率。
- **用户核验效率**：首次可用答案时间、原文打开率、正确找到出处率、追问次数。
- **运营闭环效率**：坏案例可归因率、回归关联率、修复前后复发率、版本通过率变化。

## 风险、依赖和待验证假设

- 依赖经授权的证券主数据、官方文件与版本登记；
- 同步校验可能增加延迟，需要分层：高风险结论同步、低风险答案异步抽检；
- 候选答案可能含敏感账户上下文，接口必须最小化采集并做字段级拒绝；
- 公开资料无法确认真实错误分布、用户需求规模和内部接口，用户测试状态为 **待执行**。
