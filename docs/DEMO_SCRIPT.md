# Three-minute Tencent complement demo

## 0:00–0:25 — The product decision

Open **Research guard** and point to the three-part integration panel:

> Tencent Portfolio / StockBuddy already owns the high-frequency journey: WeChat entry, market
> data, content, watchlists, alerts and broker connectivity. WealthGuard does not rebuild those
> strengths. It is invoked when a claim needs deeper evidence checking, or a failed answer needs a
> product-quality loop. This is an independent prototype, not a live Tencent integration.

## 0:25–1:05 — Financial-report evidence

Run **“Why did AAPL's FY2025 revenue change?”**. Show the resolved security, dated SEC filing,
page/paragraph locator, checksum and deterministic filing-ratio calculation. Open one cited passage.
Explain the separation between source fact, calculated result and system interpretation; if the
selected evidence cannot support the reason, the system must abstain rather than fill the gap.

## 1:05–1:30 — Announcement freshness

Run **“Is the latest ETF listing notice still current?”**. Point to publication date, retrieved
date, version status and any caution/abstention. Explain that the intended host flow passes the
security code and document version from the self-selected-stock page so a similar security or
superseded notice cannot silently enter the answer.

## 1:30–1:55 — Comparison without a winner

Run **“Compare SPY and WGBOND”** with horizon, liquidity and loss tolerance blank. Show the single
highest-information-value clarification, then open **Compare guard**. Point out source dates,
currency/product-type differences and fixed-seed synthetic calculation labels. WealthGuard does
not manufacture one “best” product.

## 1:55–2:15 — Deterministic boundary

Run **“Buy 100 shares of AAPL for me”**. Show `refuse` and `TRADE_EXECUTION`. State that the existing
licensed-broker journey remains outside WealthGuard; this system exposes no account or order route.

## 2:15–2:45 — The differentiating quality loop

Open **Quality operations**. Filter by scenario, error type or severity. Select
`WG-QA-01 CITATION_UNSUPPORTED` and walk through the user question, clarification, retrieved
evidence, citations, expected/actual result, owner and regression ID. Export the current anonymised
JSON slice. Emphasise that the eight visible records are synthetic evaluation cases, not Tencent
production incidents.

## 2:45–3:00 — Evidence and limits

Open **Evaluation** and state:

> The current fixed-seed suite passed 126/126 cases, and the official-source trace check passed
> 39/39 spans. These measure deterministic regression and source integrity—not real-user accuracy,
> production reliability, regulatory approval or business impact. User testing and Tencent
> integration remain to be done.
